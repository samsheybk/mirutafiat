⚠️
Por qué gratis no es viable en producción: en Supabase el proyecto se pausa automáticamente tras 7 días de inactividad (la intranet quedaría inaccesible), no hay backups automáticos, y en Vercel el plan gratuito no permite uso comercial. Además, las imágenes guardadas en base64 llenan los 500 MB disponibles rápidamente.
2 Desglose por servicio (plan de pago)
SupabaseS
$25/mes · Pro
  • 8 GB base de datos
  • 250 GB transferencia (egress)
  • 100 GB de archivos (storage)
  • 100.000 usuarios activos/mes
  • Backups diarios (7 días)
  • Sin pausas por inactividad
  • Soporte por email
Proyecto adicional: +$10/mes · Sobrecostos: BD $0.125/GB, egress $0.09/GB, storage $0.021/GB, cómputo Small +$5
Vercel▲
$20/mes · Pro
  • 1 TB transferencia por mes
  • Uso comercial permitido
  • $20 de crédito mensual de uso
  • Despliegues automáticos desde GitHub
  • CDN global + HTTPS
  • Soporte por email
Precio por asiento de desarrollador. El sitio es estático y las imágenes se sirven desde Supabase, por lo que el consumo real de transferencia es mínimo.
GitHubG
$0–4/mes
  • Repositorios privados ilimitados
  • Historial de versiones y colaboración
  • 2.000–3.000 min de Actions
  • GitHub Pages (gratis)
  • Soporte por email (Pro)
El plan Free ($0) es suficiente para un desarrollador. GitHub Pro ($4/mes) solo agrega más minutos de Actions, Codespaces y soporte.

4 Recomendación
Inversión recomendada
$45 – $49 /mes
≈ $540 – $588 al año
menos de $50/mes para operar en producción
1
Supabase Pro ($25/mes) es el mínimo razonable: elimina las pausas por inactividad, añade backups diarios de 7 días y sube la base de datos a 8 GB.
2
Vercel Pro ($20/mes) es necesario por la cláusula de uso comercial; tu consumo real de ancho de banda será mínimo porque las imágenes se sirven desde Supabase.
3
GitHub Free ($0) es suficiente. Si se usa con intensidad de Actions/Codespaces, GitHub Pro ($4/mes) es un costo menor.
4
El principal driver de costo es el tamaño de la base de datos (las imágenes en base64 pesan ~33% más) y el storage de archivos; ambos quedan cubiertos con holgura por el plan Pro.
✅
Resumen ejecutivo: migrar de $0 a producción cuesta aproximadamente $45–49 mensuales. No hay costos ocultos significativos al nivel de uso de una intranet corporativa; los sobrecargos (banda ancha, storage, cómputo) solo aparecerían con tráfico o volumen muy superiores a los actuales.
