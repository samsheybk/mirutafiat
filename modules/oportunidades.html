menos de $50/mes para operar en producción
1
Supabase Pro ($25/mes) es el mínimo razonable: elimina las pausas por inactividad, añade backups diarios de 7 días y sube la base de datos a 8 GB.
2
Vercel Pro ($20/mes) es necesario por la cláusula de uso comercial; tu consumo real de ancho de banda será mínimo porque las imágenes se sirven desde Supabase.
3
GitHub Free ($0) es suficiente. Si se usa con intensidad de Actions/Codespaces, GitHub Pro ($4/mes) es un costo menor.
4
El principal driver de costo es el tamaño de la base de datos (las imágenes en base64 pesan ~33% más) y el storage de archivos; ambos quedan cubiertos con holgura por el plan Pro.
✅
Resumen ejecutivo: migrar de $0 a producción cuesta aproximadamente $45–49 mensuales. No hay costos ocultos significativos al nivel de uso de una intranet corporativa; los sobrecargos (banda ancha, storage, cómputo) solo aparecerían con tráfico o volumen muy superiores a los actuales.
